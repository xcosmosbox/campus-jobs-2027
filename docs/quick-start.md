# 第一次来？先投一份，再慢慢逛

**[打开 27届秋招筛选站 →](https://autumn27-screening.ottofeng00.chatgpt.site)**

无需安装。默认游客保存，账号关联可选。你可以从下面任意一个小任务开始。

## 小任务 1：找一份产品岗

打开“机会筛选” → 展开“岗位与应届资格” → 在 **岗位／部门关键词** 填 `产品`。

“搜索公司”是另一个输入框，适合填公司名。岗位关键词匹配已录入的岗位标题和部门；数据缺失时，不会假定某公司没有这个方向。

等岗位库加载完成，再逐项加行业、城市、学历或毕业日期。多个条件必须同时满足；没有结果时，先清掉最严格的条件。

## 小任务 2：给快到期的机会挪个位置

把“截止日期”设为“未来 7 天内”，打开一个心仪机会，看看来源、日期和当前可投三个维度。

收藏且待投递、有精确截止日期的机会会进入站内待办。你也能添加自己的笔试、测评或面试时间。没有明确截止日期的机会仍可能开放，请查看官方说明。

## 小任务 3：投完后，留一张自己的小回执

从记录中的官方入口完成投递，回到详情将进度改为“已投递”，补上投递时间和简历版本。

再加一句备注，例如“这份用了产品版简历”。在“我的投递”继续记录轮次、阶段和个人优先级。

## 小任务 4：让下次换电脑更从容

右上角 **保存与账号** → **生成恢复码** → 保存完整内容 → **下载当前备份**。

同一网站换设备，在这个面板输入恢复码，点击“找回空间”。恢复码仅在生成时显示；更换会让旧码及其他设备的游客凭证失效。

从官网迁到自托管站，或反向迁移，使用 JSON 备份导入；两站的恢复码不通用。Sites 上若愿意登录，请登录后关联当前空间，之后可用账号找回。

断网修改会先保留在当前浏览器；联网后尝试同步。若出现同步差异，先看两份内容，再选择保留哪份。清除网站数据前，确认已同步，并保存恢复码或备份。

觉得某条信息不对？到 [Issues](https://github.com/xcosmosbox/campus-jobs-2027/issues) 留下公司／岗位、官方链接和核验日期，帮助下一位同学少绕一点路。
