# 2027 秋招岗位扩库与复核

核验时点：2026-10-02。范围是本站原有 203 家公司／批次，包括正式应届岗位、明确转正实习和明确接纳 2027 届的普通实习。博士后等独立申请岗位保留其真实资格，不能套用普通应届毕业窗口。

每家公司由采集者记录实际入口、读到的分页与唯一岗位、纳入和排除范围，再由两位不同审阅者独立核对公开原始响应、完整可读岗位正文和新的官方／雇主来源。审阅者对全部保存列表逐 ID、名称、机构和范围核对；新读取的代表来源用于确认现行接口与项目，不能被描述成对所有详情重新逐一抓取。最终审阅签署实际 records 和 scan 文件的 SHA-256；旧版本的补丁、删除建议及修正差异单独保留。

“核对通过”表示记录事实和已声明范围一致。它不意味着该集团所有岗位已取得、所有岗位条件已确认或岗位仍有剩余名额。动态目录无法读取、详情未取得、独立子公司尚未完整枚举、项目年份冲突等，在网站逐家公司覆盖面板和岗位详情中明确保留。

规则：

- 独立职位必须有真实申请项／岗位 ID 或可核对的完整雇主职位，不把招聘人数、宣传方向、纯跳转提示拆成多个岗位。
- 只收入确有当届项目或资格证据的岗位。非当届、无当届证据的社招和存在未解决年度冲突的候选不计入确认目录。
- 截止日期必须有实际申请含义。不用发布日期、刷新时间、API 模板有效期、毕业时间或面试日推算投递期限。
- 月份毕业窗口保留原文，不虚构精确日期；学历偏好不当成最低硬门槛；职责中的“办理员工转正”不当成岗位留用承诺。
- 同真实职位编号、机构、城市和完整职责／要求的重复刊登去重，按实际最新发布日期保留。不同城市或机构的真实独立申请项不合并。
- 官方公开职位仍存在但申请链接不可用时，来源可确认，当前可投保持未知。

原中国银行六条岗位概览及广汽两条方向概览从当前目录移出，避免与新具体职位重复计数。用户已保存的原投递进度、笔记和待办保留；一条概览对应多个真实岗位时，不擅自把进度转给其中某一个。宁波原“算法”概览合并到其真实科技岗位时保留原跟进记录。

公共源码包含岗位数据、来源、覆盖范围及两轮独立复核结论。原始抓取与研究归档不在公共源码包中。

核心验证包括：“产品”搜索实际岗位、行业／公司／性质／日期／来源组合条件必须命中同一岗位、分页不遗漏已匹配岗位、未知期限不会继承公司概览日期，以及原投递／待办数据兼容。部署保留现有私密权限。

服务端只打包岗位 ID 与分片位置索引，保存投递进度不必加载岗位全文。首次修改原始岗位时，通过内部静态资源绑定读取对应分片，核对版本后再计算修改历史，最多缓存两个分片。资源读取失败或版本不符时不写入记录，避免产生错误的原始值；旧投递、概览、待办和用户隔离规则保持兼容。

大库通过 29 份带版本标识的数据文件分批加载，页面脚本只携带索引。载入完成后才启用具体岗位视图，全部岗位参与本地筛选；读取失败、版本不一致、重复／缺失岗位不会被当成“零岗位”，页面提供重试。数据交付测试逐字段比较全部 28,819 条，与源目录保持一致。预览浏览器在整库加载时出现协议超时，后续控制也不可用；最终浏览器交互验证受此环境问题影响，筛选、分页、数据加载和保存通过直接执行实际代码的测试验证。
